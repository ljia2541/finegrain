# 📖 Cloudflare Pages 完整配置指南

## 🎯 你现在需要完成的步骤

### 步骤 1：创建 KV 命名空间

**1.1 找到 Workers & Pages**

在 Cloudflare Dashboard 首页，你应该看到：
- 左侧菜单栏
- 找到 **「Workers & Pages」**（通常在靠下的位置）

**1.2 创建 KV 命名空间**

1. 点击「Workers & Pages」展开菜单
2. 点击 **「KV」**
3. 点击右上角 **「创建命名空间」** 按钮
4. 输入名称：`finegrain-kv`
5. 点击「添加」

**✅ 完成标志：** 看到名为 `finegrain-kv` 的命名空间出现在列表中

---

### 步骤 2：创建 Cloudflare Pages 项目

**2.1 访问 Pages 页面**

方法 1：直接访问
```
https://dash.cloudflare.com/b8122ff3f404b8271bc74f4ede888c79/pages/view/create
```

方法 2：从 Dashboard 导航
1. 在左侧菜单找到 **「Workers & Pages」**
2. 点击 **「Pages」**
3. 点击 **「创建项目」**
4. 选择 **「连接到 Git」**

**2.2 连接 GitHub**

1. 点击 **「连接到 Git」**
2. 你可能需要授权 Cloudflare 访问 GitHub
3. 授权后，会显示你的 GitHub 仓库列表
4. 找到并选择 **「finegrain」** 仓库

**2.3 配置构建设置**

看到配置页面后：

```
项目名称：finegrain（自动填充）
生产分支：main
构建命令：npm run build
构建输出目录：public（或使用智能默认值）
根目录：/
Node.js 版本：18.17.0
```

**重要提示：**
- 如果有「使用智能默认值」选项，**点击它！**
- Next.js 构建后的输出在 `.next` 目录，但 Cloudflare 会自动处理

**2.4 环境变量（可选，但推荐）**

向下滚动到「环境变量」部分：

```
变量名：REPLICATE_API_TOKEN
值：r8_JeOhr26s71o4Qq9bU2wEsahBzsjgfUN1wvlpH
环境：生产环境和预览环境都勾选
```

**2.5 完成创建**

1. 点击 **「保存并部署」**
2. 等待首次部署完成（3-5 分钟）

**✅ 完成标志：** 看到「部署成功」提示，并得到一个 `*.pages.dev` 域名

---

### 步骤 3：绑定 KV 命名空间

**3.1 进入项目设置**

1. 在 Pages 项目页面
2. 点击顶部的 **「设置」** 标签
3. 点击左侧的 **「Functions」**

**3.2 添加 KV 绑定**

1. 向下滚动找到 **「KV 命名空间绑定」** 部分
2. 点击 **「添加绑定」**

**3.3 配置绑定**

```
变量名称：KV
KV 命名空间：选择 finegrain-kv（从下拉菜单选择）
```

**3.4 保存配置**

1. 环境选择：**生产环境和预览环境** 都勾选
2. 点击 **「保存」**
3. 点击 **「重新部署」**（使绑定生效）

**✅ 完成标志：** KV 绑定出现在列表中

## ❓ 常见问题

### Q1：找不到「Workers & Pages」菜单
**A：** 在首页顶部搜索框输入「Workers」，应该能找到

### Q2：GitHub 仓库不显示
**A：** 点击「添加 GitHub 账户」重新授权

### Q3：构建失败
**A：** 检查 Node.js 版本是否设置为 18.x

### Q4：KV 绑定后还是不工作
**A：** 必须点击「重新部署」才能生效
