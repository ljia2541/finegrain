# 示例图片说明

这个目录用于存放示例对比图片，展示模糊→清晰的效果。

## 文件命名规范

- `portrait-blurry.jpg` - 模糊的人像照片
- `portrait-clear.jpg` - 清晰的人像照片（增强后）
- `landscape-blurry.jpg` - 模糊的风景照片
- `landscape-clear.jpg` - 清晰的风景照片（增强后）
- `old-photo-blurry.jpg` - 模糊的老照片
- `old-photo-clear.jpg` - 清晰的老照片（增强后）
- `product-blurry.jpg` - 模糊的产品照片
- `product-clear.jpg` - 清晰的产品照片（增强后）

## 临时解决方案

目前使用占位图片。你可以：

1. **添加真实的对比示例**：
   - 上传模糊的原图
   - 使用 Replicate API 增强图片
   - 下载增强后的图片
   - 放到这个目录

2. **使用在线示例图片**：
   - 从 Unsplash/Pexels 下载示例图片
   - 使用图像编辑器创建模糊版本
   - 将原图和模糊版本放在这里

3. **从项目截图生成示例**：
   - 使用项目实际处理的前后对比图
   - 隐去敏感信息
   - 放在 public/examples/ 目录

## 推荐尺寸

- 宽度：1200px
- 高度：800px
- 格式：JPG（质量：85）
